# 見た目の需要

作成: 2026-10-29（T018）。所有者の問い「UI にこだわる人が工場の操作盤を選ぶのか」に、数字で答えるための調査。
印: 「調査で確認」はページで数字を見たもの、「推測」はそこからの判断。

## 調べ方

UI に関心のある人を 3 つに分け、それぞれが実際に選んだ・褒めた・保存した・買った数を、見た目の系統ごとに集めた（調査で確認の方法）。

1. ゲームの UI が好きな人とデザイナー: YouTube の再生数、Hacker News の点数、GitHub の星
2. 開発者・自宅サーバー・Home Assistant の利用者: GitHub の星、Home Assistant の掲示板の閲覧数といいね
3. 有料の UI 素材: ThemeForest の販売数、Unity Asset Store と itch.io の評価件数、Booth のスキ（♡）。Booth で数字が取れた品は、配信素材ではなく TRPG をオンラインで遊ぶ道具（ココフォリア）の背景・演出素材だった

見た日はすべて 2026-10-29。Reddit・Dribbble・Behance・ArtStation・Etsy・gameuidatabase.com は取得を拒否されたので数字は無い。英語圏の配信者の好みは判定できていない。

系統の分け方: 1 SF の HUD（暗い地に青・水色の細線）、2 日本のゲームの大胆な画面（ペルソナ、ゼンレスゾーンゼロ）、3 すっきりした技術系（アークナイツ、エンドフィールド。白・黒・灰に差し色 1 つ、規格の札、細い格子）、4 重い工業風（黄黒の縞、鉄板、鋲）、5 古い端末、6 古い OS とドット絵、7 印刷調（リソグラフ、ブルータリズム）、8 ガラスや Apple 風のすっきりした画面、9 作品そのもの（LCARS など）、10 サイバーパンクのネオン、11 かわいい・くつろぎ系。
案A は系統 1、案B は系統 7、案C は系統 4 にあたる。

## 好まれる理由

- **ゲームの UI が好きな人が名指しで褒めるのは、系統 2 と系統 3 である**（調査で確認）。ペルソナ風のメニューは、個人が真似して作った動画が 69 万回見られている。褒められる点は、色を 2〜3 色に絞ること、文字の組み方、メニューを開くたびの動きである。一方で、ペルソナの監督は初期案が読めなかったと認めている（https://www.pcgamer.com/games/rpg/persona-series-director-says-atluss-flashy-menus-are-actually-really-annoying-to-design ）。
- **系統 3 は、ゲームの中では褒められているのに、Web の部品がほとんど無い**（調査で確認。ak-ui は星 66）。部品が足りていない可能性はある（推測）。ただし系統 3 の根拠はゲームの動画の再生数だけで、Web の部品が欲しいという数字は無い。系統 4 の数字が小さいことを「需要が無い」と読むなら、系統 3 の Web の部品の少なさも同じく需要が無い印と読める。
- **開発者が星を付けるのは、系統 1 と系統 5・6 である**（調査で確認）。元ネタがすぐ分かり、映画の小道具や懐かしさを感じさせる見た目が好まれていると考えられる（推測）。
- **星の数は興味の数で、使われている数ではない**（推測）。eDEX-UI は保守を終えて凍結されていて、星 4.5 万は「見て面白い」の数である。系統 1 の強さも、毎日使われることまでは示していない。
- **毎日見る画面では、すっきりした系統 8 が圧倒的に強い**（調査で確認。Mushroom の閲覧は 167 万で、LCARS の 20 倍）。派手な見た目は「見て楽しむ」「人に見せる」ために選ばれている（推測）。
- **工業らしさは、警告の縞や鋲ではなく、札と罫線で整えた形なら受け入れられている**（調査で確認。計測器風の Metrology は星 688 で、Home Assistant の作品風の見た目より多い）。
- **黄黒の縞は、画面全体の見た目としてではなく、部分的な演出として買われている**（調査で確認。Booth の KEEP OUT 素材はスキ 1,269。一方、黄黒の縞を全体に使った UI の部品集は、Unity・itch.io・ThemeForest で反応がほぼ無い）。

## 案との照合

| 案 | 系統 | 需要 | 判定 |
|---|---|---|---|
| 案A 夜の地形図 | 1 | 開発者の星 4.5 万、管理画面の雛形の販売 3.6K 本、TRPG 素材のスキ 3,413。配信者の数字は取れていない | 3 案の中で最も強い。ただし星は興味の数で、使われている数ではない。ただし ThemeForest の HUD と似ていて、UI 好きからは「よくある」と見られやすい（推測） |
| 案B リソグラフ印刷 | 7 | 近い仲間のネオブルータリズムには星 5,627 がある。リソグラフの画面そのものはスキ 1〜2 | 需要の証拠がほぼ無い |
| 案C 工場の操作盤 | 4 | 最も強い例で星 232（nerv-ui）。有料の UI 素材は評価 0〜4 件 | 最も弱い。所有者の疑問は数字で裏付けられた |

案C を推した前回の理由（暗い地で配信に重ねやすい、青い SF 風から離れられる）は、需要を調べずに立てたものだった。この調査で、その推奨は取り下げる（調査で確認の数字による）。

## 結論

- 案C は主の見た目にしない。黄黒の縞は、警告を出すときの飾り（`hazard` の part）としてだけ残す。
- 案B は主の見た目にしない。需要の証拠が無い。
- 案A は 3 案の中で需要の数字が最も大きい。ただし既製品と似るので、そのままでは差が出にくい（推測）。
- 候補に無かった系統 3（すっきりした技術系）は、ゲームの UI としては褒められている。Web の部品として求められている数字は無い。それでも案A と並べて比べる価値はある（推測）。
- 系統 2（日本のゲームの大胆な画面）は最も熱心に褒められているが、元にした作品の見た目（大きな文字、傾いたパネル、強い 2〜3 色）と重なるので、CHARTER.md の制約から主にはしない。
