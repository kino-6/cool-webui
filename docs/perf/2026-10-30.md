# 負荷の測定 2026-10-30

demo/home.html（タイル）を headless Chrome、1600×900 で、場面ごとに 30 秒開いた。
CPU はメインスレッドの作業時間の割合（Chrome DevTools Protocol の TaskDuration の差 ÷ 経過時間）。
1 コマの時間は requestAnimationFrame の間隔の 95 パーセンタイル。背景の描画数は aura が描いた回数。
headless なので GPU の負荷は入っていない。合否の線はまだ置かない（components.md の「負荷を測る手順」）。

| 場面 | CPU % | 1 コマ p95 ms | 背景の描画数 |
|---|---|---|---|
| full | 4.7 | 16.7 | 936 |
| calm | 1.5 | 16.8 | 0 |
| off | 1.4 | 16.8 | 0 |
| bg=none | 5.4 | 16.7 | 0 |

所見: 背景なし（bg=none）が full より重く出た。背景の描画を省いているので軽くなるはずで、測定の揺れか、ほかの原因（数字の転がり・流れる帯）がある。6 秒の版では bg=none が 2.9%、full が 4.1% だった。次の測定で回数を増やして確かめる。
